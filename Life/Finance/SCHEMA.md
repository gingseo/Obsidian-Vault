# Finance 폴더 작성 스키마

이 문서는 `Life/Finance/` 폴더(및 별도로 독립한 `News Journal/`)에 노트를 작성(사람이든 클라우드 routine이든)할 때 따르는 규칙이다. **클라우드 스케줄(routine)은 실행 시 이 문서를 먼저 읽고 아래 규칙에 맞춰 작성한다.**

## 폴더별 역할

| 폴더 | 역할 | 파일 단위 |
| --- | --- | --- |
| `Life/Finance/Wiki/` | 개념·용어 정리 | 노트 하나 = 개념 하나, `[[링크]]`로 상호 연결 |
| `Life/Finance/Companies/` | 종목/산업 분석 | 노트 하나 = 종목 또는 산업군 하나 |
| `Life/Review(책, 강의)/` | 책/강의 리뷰 | 노트 하나 = 자료 하나. frontmatter `Type`(책/강의), `Status`(읽는 중/완료) |
| `News Journal/` (볼트 최상위, Finance 밖) | 뉴스·이슈 저널 (자동화 대상) | **일자별 파일**, 월 폴더 안에 저장 |
| `Life/Finance/Trade Log/` | 매매일지 | 거래 1건 = 노트 1개, 거래 발생 시에만 작성 |

## News Journal 작성 규칙

`News Journal/`은 `Finance/` 하위가 아니라 볼트 최상위 폴더다 (경제 공부 허브와 분리해 독립시킴).

### 파일 구조

```
News Journal/
  2026-08/
    2026-08-07.md              ← 매일 기록
    2026-08-08.md
    _Weekly-2026-08-09.md      ← 주간 리뷰 (해당 일요일 날짜)
    _Monthly-2026-08.md        ← 월간 리뷰 (그 달 폴더에 저장, "지난달"을 정리)
```

- 매일 기록: `News Journal/YYYY-MM/YYYY-MM-DD.md`. 월 폴더(`YYYY-MM/`)가 없으면 새로 만든다. 파일이 이미 있으면 **절대 덮어쓰지 않는다** — 그날 안에 추가로 기록할 내용이 있으면 파일 끝에 이어 붙인다. 파일 최상단은 `# YYYY-MM-DD` 제목으로 시작한다.
- 주간 리뷰: `News Journal/YYYY-MM/_Weekly-YYYY-MM-DD.md` (YYYY-MM-DD는 리뷰 시점의 일요일 날짜, 그 날짜가 속한 월 폴더에 저장). 제목은 `# 주간 리뷰 (YYYY-MM-DD 기준 최근 1주)`.
- 월간 리뷰: `News Journal/YYYY-MM/_Monthly-YYYY-MM.md` (YYYY-MM은 리뷰가 생성되는 새 달, 즉 그 폴더 자신의 월). 제목은 `# 지난달 리뷰 (YYYY-MM, 전달 기준)`. 이미 파일이 있으면 중복 생성하지 않는다.

파일명이 밑줄(`_`)로 시작하는 `_Weekly-*`, `_Monthly-*`는 날짜별 기록이 아닌 리뷰 파일임을 나타낸다.

### 오늘의 경제 뉴스 작성 형식

단순 리스트 나열이 아니라 **주제별로 묶어서** 소제목과 태그를 붙인다.

```markdown
### 오늘의 경제 뉴스

#### 중동 리스크 #지정학 #유가
- 이란 의회, 호르무즈 해협 통항 전면 금지 법안 검토 — WTI 3.4%·브렌트유 4%대 급등 ([기사](URL))
- 호르무즈 리스크로 뉴욕증시 일제히 하락 ([기사](URL))

#### 국내 거시지표 #한국경제 #무역수지
- 한국은행, 6월 경상수지 497억 3000만달러 흑자로 역대 최대 기록 (뉴스핌 관련 발표 기반)
```

묶는 주제는 미리 정해두지 않는다 — 그날 뉴스 성격에 맞춰 자유롭게 소제목을 만든다 (예: 중동 리스크, 국내 거시지표, 통화정책, 고용지표, 정부 정책 등). 소제목에는 뉴스 성격을 나타내는 태그를 1~2개 붙여서, 나중에 `FROM #지정학`처럼 주제별로도 조회할 수 있게 한다. 소제목 아래 헤드라인은 기존처럼 `- 헤드라인 요약 ([기사](URL))` 형식을 유지한다.

### 국장/미장 구분

변동성 정리는 항상 **국장(한국 증시)** / **미장(미국 증시)**으로 나눈다. 미국 증시 데이터가 아직 없으면(장 진행 전/중) 억지로 지어내지 말고 "데이터 없음 또는 장 진행 전"이라고 명시한다.

### 종목 항목 작성 형식 (핵심)

변동성 있었던 종목마다 아래 형식을 그대로 따른다.

```markdown
#### **삼성전자** #반도체 #IT

| 시가 | 종가 | 등락률 | 거래대금 |
| --- | --- | --- | --- |
| 71,000 | 64,700 | -9.0% | 3.2조 |

| 구분 | 순매수/매도 |
| --- | --- |
| 외국인 | -1,200억 |
| 기관 | -800억 |
| 개인 | +2,000억 |

2분기 잠정실적 영업이익 89.4조원(+1,810% YoY)으로 컨센서스(85.5조원) 상회하는 <mark style="background: #FF5582A6;">역대급 실적</mark>에도 주가는 <mark style="background: #FF5582A6;">9% 급락</mark>. 눈높이 과열에 따른 기대치 대비 실망 매물로 해석.
- 관련 기사: [헤드라인](URL)
```

**시가·종가·등락률·거래대금은 최대한 조사해서 채운다.** 네이버금융, 다음금융, 인베스팅닷컴 등 시세 정보를 제공하는 곳을 함께 검색해서 실제 수치를 찾는 것을 우선한다. 그래도 특정 값을 못 찾으면 그 칸만 `-`로 표시한다 (표 자체를 생략하지 않는다 — 시가/종가 중 하나라도 구했으면 표는 넣고 나머지 칸만 `-`). 수급 주체별(외국인/기관/개인) 표도 마찬가지로, 구한 값만 채우고 못 구한 행은 아예 빼거나 `-`로 표시한다. 어떤 수치도 전혀 못 구했을 때만 표 전체를 생략한다.

### 태그 규칙

각 종목 항목의 소제목 줄에 태그를 붙인다.

- **종목 태그**: 종목명 그대로 붙인 것 (`#삼성전자`, `#한화오션`). 나중에 `FROM #삼성전자`로 해당 종목 전체 이력을 날짜순 조회하기 위함.
- **섹터 태그**: 업종/테마 (`#반도체`, `#방산`, `#바이오`, `#화장품`, `#2차전지`, `#IT`, `#조선` 등). 하나의 종목에 여러 섹터 태그를 붙여도 된다.
- 산업군 단위로만 언급되고 특정 종목이 없으면 종목 태그 없이 섹터 태그만 붙인다.
- 새로운 섹터가 나타나면 자유롭게 새 태그를 만든다 — 태그 목록을 미리 정해두지 않는다.

### 핵심 키워드 하이라이트

아래에 해당하는 단어(또는 그 단어가 들어간 짧은 구)가 나오면 `<mark style="background: #FF5582A6;">...</mark>`로 감싼다.

> 실적, 급락, 급증, 급등, 폭락, 폭등, 실망, 서프라이즈, 강세, 약세, 상승, 하락, 컨센서스 상회/하회, 순매수, 순매도, 상한가, 하한가

과용하지 않는다 — 항목당 정말 중요한 곳 한두 군데에만 사용한다. 문장 전체를 감싸지 않고 핵심 단어/수치 위주로 짧게 감싼다.

### 가독성

- 원문 기사를 그대로 긁어오지 않는다. 핵심만 요약하고, 헤드라인과 링크만 원문 그대로 남긴다.
- 종목/산업군명은 소제목(`####`)과 볼드로 강조하고, 본문 서술은 3줄 이내로 압축한다.
- 관련 기사는 하위 불릿으로 `- 관련 기사: [헤드라인](URL)` 형식으로 붙인다.

### Dataview로 나중에 조회하는 방법 (참고)

```dataview
LIST
FROM "News Journal" AND #삼성전자
SORT file.name DESC
```

```dataview
LIST
FROM "News Journal" AND #방산
SORT file.name DESC
```

`News Journal/_Index.md`에 위와 같은 쿼리 블록이 이미 있다. 새 태그를 쓰기 시작하면 그 문서에 쿼리를 추가해도 된다.

## Trade Log 작성 규칙

파일명: `YYYY-MM-DD 티커 매수/매도.md`. frontmatter는 `Date`, `Ticker`, `Action`, `Price`, `Quantity`를 채운다. 매매 이유와 회고는 본문 콜아웃에 자유 기록.

## Wiki / Companies / Review 작성 규칙

- 새 개념·종목·자료를 다룰 때, 이미 관련 노트가 있으면 새로 만들지 말고 `[[링크]]`만 추가한다.
- 각 폴더의 `_Index.md`는 Dataview 쿼리로 자동 목록화되므로 직접 수정하지 않는다.
