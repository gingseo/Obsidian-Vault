# 역할
"N개의 예측"과 "M개의 정답(ground truth)"이 있을 때, **어떤 예측이 어떤 정답을 담당할지 1:1로 짝을 지어주는 알고리즘**. 신경망 레이어가 아니라 손실 함수를 계산하기 전에 수행하는 **최적화 알고리즘**이다.

# 구조

## 입력/출력
- 입력: 예측 집합 `ŷ = {ŷ_1, ..., ŷ_N}`과 정답 집합 `y = {y_1, ..., y_M}` (보통 `N > M`이라 정답을 "no object"(∅)로 패딩해 크기를 N으로 맞춘다), 그리고 모든 (예측, 정답) 쌍에 대한 "매칭 비용" `N×N` 행렬.
- 출력: 각 정답에 예측 하나씩을 배정하는 순열(permutation) `σ` — "이 정답은 이 예측이 맡는다"는 1:1 대응표.

## 내부 동작
1. **비용 행렬 계산**: 예측 i와 정답 j를 짝지었을 때 드는 "비용"(클래스가 틀리면 크게, 박스 위치가 다르면 크게)을 모든 조합에 대해 계산해 `N×N` 행렬을 만든다.
2. **최소 비용 매칭 탐색**: 이 행렬에서 "각 행/열이 정확히 한 번씩만 선택되면서 전체 비용 합이 최소가 되는" 조합을 찾는다 — 이걸 전수조사하면 `N!`가지라 너무 느리므로, **헝가리안 알고리즘**(다항 시간, `O(N³)`)으로 빠르게 찾는다.
3. **결과 적용**: 찾은 매칭에 따라 "이 예측은 이 정답과 비교해서 손실을 계산해라"가 확정되고, 그 이후에야 비로소 일반적인 손실(분류 loss, 박스 회귀 loss 등)을 계산한다.

> [!example]- DETR에서의 구체적 비용 정의
> ```
> L_match(y_i, ŷ_σ(i)) = -1[c_i≠∅]·p̂_σ(i)(c_i) + 1[c_i≠∅]·L_box(b_i, b̂_σ(i))
> ```
> 클래스가 맞을 확률이 높을수록, 박스 위치가 정답과 가까울수록 비용이 낮아진다. "no object"로 매칭된 예측은 박스 비용을 계산하지 않는다(`c_i=∅`일 때 두 항 모두 0).

# 왜 이렇게 되는가
- **왜 필요한가(anchor/NMS와의 차이)**: 기존 detector는 anchor box나 grid cell처럼 "미리 정해둔 위치 규칙"으로 예측-정답을 대응시키고, 중복 예측은 NMS(비최대 억제)라는 후처리로 걸러낸다. DETR은 이런 사람이 설계한 규칙을 없애고, "이번 배치의 예측과 정답을 보고 그때그때 최적의 1:1 대응을 찾는" 방식으로 대체한다.
- **왜 "집합(set) 예측"이라 부르는가**: 예측들 사이에 순서가 없다(순열 불변, permutation-invariant) — 모델이 정답을 1번, 2번, 3번 슬롯 중 어디에 뱉어도 상관없고, 매칭 알고리즘이 사후에 "누가 누구 담당인지"를 정해준다. 그래서 모델은 순서를 신경 쓰지 않고 "존재하는 객체들의 집합"만 잘 예측하면 된다.
- **왜 중복 예측을 걸러내는 효과가 생기는가**: 한 정답에는 예측이 정확히 하나만 매칭되므로(1:1), 같은 객체를 여러 예측이 동시에 맞히려 해도 학습 신호(loss)는 그중 하나에만 간다 — 나머지 예측은 "no object"에 매칭되어 억제되도록 학습된다. 이 효과 덕분에 NMS 같은 후처리가 불필요해진다.

# 등장 논문
- [[DETR]] — 예측 N개(=100)와 정답(패딩 포함 N개)을 헝가리안 알고리즘으로 매칭한 뒤, 그 매칭 결과로 Hungarian loss(분류 + 박스 loss)를 계산. 이 매칭 덕분에 anchor generation과 NMS를 모두 제거할 수 있었다는 것이 DETR의 핵심 기여 중 하나.
