# Abstract
전천후·전일 능동 촬영 능력을 가진 합성개구레이더(SAR)는 지구과학 분석과 사회경제적 응용에 필수적인 도구가 되었다. 딥러닝 기반 객체 탐지가 발전했음에도, SAR 영상에서 소형 객체를 빠르고 정확하게 탐지하는 것은 극도로 제한된 픽셀 표현, 밀집 분포에서의 흐릿한 경계, 학습 중 양성-음성 샘플 불균형 때문에 여전히 큰 과제로 남아있다. 최근 CLIP(Contrastive Language-Image Pre-Training) 같은 비전-언어 모델이 강력한 크로스모달 의미 모델링 능력으로 폭넓은 연구 관심을 받고 있다. 그러나 SAR 영상에서 소형 객체의 정밀한 위치 파악과 탐지를 가이드하는 잠재력은 아직 충분히 탐구되지 않았다. 이 한계를 극복하기 위해, 우리는 CLIP-Driven Adaptive Tiny Object Detection Diffusion Network(CDATOD-Diff)를 제안한다. 이 프레임워크는 크로스모달 의미적 prior를 활용해 효과적인 양성 샘플의 부족을 완화하는 CLIP 이미지-텍스트 인코딩 가이드 동적 샘플링 전략을 도입한다. 나아가, 생성적 diffusion 기반 모듈이 반복적 디노이징을 통해 샘플링 프로세스를 재구성해 맥락 인식(contextual awareness)을 강화한다. 회귀 불안정성 문제를 해결하기 위해, 코너 위치 파악을 스케일 변화로부터 분리하고 미세한 위치 오차에 대한 민감도를 줄이는 Balanced Corner-IoU(BC-IoU) loss를 설계해 바운딩 박스 예측을 안정화한다. 다수의 SAR 및 광학 원격탐사 데이터셋에서 수행한 광범위한 실험은 CDATOD-Diff가 복잡한 배경과 밀집 분포를 가진 어려운 소형 객체 시나리오에서 탐지 견고성과 위치 파악 정확도를 크게 향상시켜 최신 최고 성능을 달성함을 보여준다.

# Introduction

#### SAR 소형 객체 탐지의 어려움
자연 이미지와 달리 SAR 영상의 극소형 객체는 수십 픽셀에 불과해 텍스처·형태·색상 정보가 제한적이며, 밀집 배치 시 feature map 경계가 흐려져 위치 파악 정확도가 떨어지고 박스 중복으로 중복 탐지가 발생한다.

#### 기존 소형 객체 강화 전략의 개요
데이터 증강(GAN 기반), 맥락 정보 융합, 특화된 학습 패러다임(anchor 설정, 양성-음성 샘플 할당, 손실 함수) 세 방향이 주로 쓰이지만, 각각 한계가 있다.

#### CLIP 활용의 미개척 영역
CLIP 등 비전-언어 모델이 open-vocabulary 탐지에 효과적임이 입증되었지만, SAR 영상의 정밀한 위치 파악 요구사항과 스케일 편차 문제에 CLIP을 직접 적용한 연구는 아직 부족하다.

#### 이 논문이 지적하는 근본 문제
소형 객체의 극소 크기가 정적 샘플링 패러다임과 근본적으로 맞지 않아, 기존 샘플링 포인트와 효과적으로 대응하지 못하거나 매칭이 미미한 수준에 그치며, 맥락 prior를 충분히 반영하지 못해 양성-음성 샘플 불균형이 심화된다.

#### 제안 방법 개요
CLIP이 가이드하는 동적 위치 prior로 샘플링 프로세스를 최적화하는 CDATOD-Diff와, 바운딩 박스 회귀 견고성을 높이는 재설계된 회귀 손실 함수를 제안한다.

#### 기여 요약
소형 객체 탐지를 위한 통합 탐지 프레임워크, CLIP 기반 동적 anchor 샘플링 전략, 그리고 스케일 변동의 영향을 줄이는 BC-IoU 회귀 손실 함수를 기여로 제시한다.

# Main Contribution
1. CDATOD-Diff는 스케일 변화 조건에서 소형 객체 탐지를 위해 특별히 설계된 통합 탐지 프레임워크로, 기존 아키텍처가 어려움을 겪는 상황에서 탐지 견고성과 위치 파악 정확도를 크게 향상시킨다.
2. 혁신적인 CLIP 기반 동적 anchor 샘플링 전략을 도입해, 샘플링 단계에서 CLIP의 가이드 아래 불충분한 양성 샘플 문제를 해결한다.
3. 샘플 회귀 단계를 위한 견고한 적응형 회귀 손실 함수 BC-IoU를 제안해, 특정 시나리오에서 소형 객체가 겪는 회귀 문제를 개선하고 스케일 변동의 영향을 줄인다.

# Conclusion
이 연구는 원격탐사 영상에서 소형 객체 탐지를 위한 알고리즘 설계를 체계적으로 조사하며, 학습 중 샘플 불균형 문제와 박스가 특수한 상대적 위치에 있을 때의 바운딩 박스 회귀 어려움을 다룬다. 이 문제들을 해결하기 위해, 샘플링 최적화와 적응형 회귀 정제를 통합한 소형 객체 탐지 프레임워크 CDATOD-Diff를 제안한다. Anchor-free 단일 스테이지 FCOS 알고리즘을 baseline으로 삼아, 비전-언어 모델을 활용해 샘플링 포인트를 실제 타겟 쪽으로 편향시키면서 소형 객체 샘플 수를 늘리는 CLIP 기반 생성적 샘플링 모듈을 도입해 탐지 성능을 향상시킨다. 동적 가중치 인자를 갖는 corner-IoU 손실 함수를 설계함으로써, 예측 바운딩 박스와 GT 주석이 겹치지 않거나 포함 관계에 있는 상태에서 발생하는 회귀 어려움을 완화한다. 이 혁신은 네트워크가 다양한 조건에서 효과적인 회귀를 유지할 수 있게 하며 소형 객체 탐지 정확도를 더욱 향상시킨다. 다수 데이터셋에 걸친 광범위한 실험이 제안 방법의 효과성을 입증한다.
