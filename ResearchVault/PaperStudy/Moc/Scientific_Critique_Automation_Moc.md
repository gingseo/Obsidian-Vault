# 이 분야가 다루는 핵심 질문
- 논문 저자가 스스로 밝히지 않은("unstated") 한계를 LLM 에이전트가 어떻게 체계적으로 찾아낼 수 있는가?
- 멀티에이전트 비평 시스템에서, 에이전트들이 뻔한 문제로 쏠리는(groupthink) 현상을 어떻게 막을 것인가?

# 지금까지 다룬 흐름
- [[Tree-of-Concerns]] — 이 위키에서 이 task를 여는 첫 논문. Scope/Methodology/Theoretical/Reproducibility/Fairness 5개 전문화 skeptic persona가 독립 병렬 트리에서 4단계 적대적 논쟁으로 미기재 한계를 추출하고, 사후 Panel Review로 카테고리 드리프트·중복을 조정하는 프레임워크와 전용 벤치마크(ToC-Bench)를 함께 제안. 컴퓨터 비전이 아니라 LLM 멀티에이전트 시스템 설계 논문이며, 직접 정독하려던 것이 아니라 커뮤니티에서 화제라 트렌드 파악 차원에서 읽은 논문(`source_type: community`).
