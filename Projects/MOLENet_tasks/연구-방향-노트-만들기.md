# 연구 방향 아이디어: 인코더 고해상도 레벨(C3) 강화

## 아이디어
[[2021_ICLR_Deformable-DETR|Deformable-DETR]]의 multi-scale deformable attention encoder에서, 가장 고해상도인 C3 레벨(작은 객체 정보가 가장 많이 남아있는 레벨)에 "객체가 있을 법한 영역"을 미리 강조하는 신호를 추가해서 인코더에 넣으면 어떨까 — 라는 질문에서 출발.

## 근거 — 이미 실증된 부분

- **멀티스케일 입력 자체의 기여가 정교화보다 크다**: [[2021_ICLR_Deformable-DETR|Deformable-DETR]] Table 2 ablation에서 "MS inputs 추가"만으로 AP_S가 21.2→24.1(+2.9), 여기에 "MS attention"까지 더하면 24.1→26.4(+1.6) — 두 단계 합쳐 AP_S 기준 +5.2로 이 테이블에서 가장 큰 개선폭. Sampling point 수(K) 증가는 +0.7에 그침. → 고해상도 레벨(C3) 자체의 정보 품질이 전체 성능에 미치는 영향이 크다는 뜻이고, 그 레벨을 한 번 더 정제하면 상승 여력이 있을 수 있다는 근거.
- **C3(또는 그에 준하는 고해상도 레벨)를 강화하는 게 의미 있다는 건 이미 실증된 방향**: [[2024_ECCV_DQ-DETR|DQ-DETR]]의 CGFE(Counting-Guided Feature Enhancement)가 정확히 이 아이디어를 실현. Density map을 spatial+channel attention(CBAM 방식)으로 encoder feature에 곱해 전경 영역을 강조하는데, ablation(Table 5)에서 **CGFE 단독 기여가 +3.2 AP로 이 논문에서 가장 큰 개별 기여**(DQS 단독 기여 +2.2 AP보다 큼). → **[나중에 내 연구에 쓸 것]**

## 리스크 — 실패 사례로 이미 관찰된 부분

- **강화 신호 자체의 오류가 그대로 전파된다**: [[2024_ECCV_DQ-DETR|DQ-DETR]]의 CCM(density map으로 인스턴스 수를 4단계 분류하는 서브태스크)이 **N>500 구간에서 분류 정확도 56.6%로 급락**하고, 이 구간의 AP 개선폭도 다른 구간(+2.1~4.0)보다 작은 **+1.2에 그침** — "강조 영역을 알아내는 것" 자체가 detection과 순환 논리에 가까운 서브태스크이고, 학습 샘플이 적은 구간(46장)에서는 이 서브태스크 자체가 불안정해진다는 걸 정량적으로 보여준 사례. → **[나중에 내 연구에 쓸 것]**

## 생각해볼 점

- **인코더 self-attention과 역할이 겹칠 수 있음**: Deformable attention 자체가 이미 offset을 통해 "어디를 볼지"를 학습으로 알아낸다. C3에 별도 강조를 추가하면 "이미 학습으로 배우고 있는 것을 명시적 모듈로 한 번 더 강요"하는 셈일 수 있다. [[2021_ICLR_Deformable-DETR|Deformable-DETR]] Table 2에서 FPN을 추가해도 AP가 그대로였던 것(43.8→43.8, "attention이 이미 레벨 간 정보를 충분히 교환한다"는 근거)과 유사한 saturation이 재현될 가능성.
- **연산량 증가**: [[2024_ECCV_DQ-DETR|DQ-DETR]]의 CGFE는 spatial+channel attention을 추가 연산으로 붙였는데, 논문이 FLOPs·FPS를 전혀 보고하지 않음 — 성능은 오르지만 비용 트레이드오프가 불투명하다는 게 이미 지적된 한계. 내 연구에서는 이 비용을 명시적으로 측정·보고할 필요.

## 개선해야 할 점

- **"강화 신호"가 틀렸을 때의 리스크(양날의 검)**: 강조 영역 예측이 틀리면, 실제로 객체가 있는데 약화된 영역의 정보가 오히려 인코더에 덜 들어가게 되어 recall이 떨어질 수 있다 — "아무것도 안 하는 것"보다 나쁜 결과를 낼 수 있는 구조. CCM의 낮은 정확도 구간(N>500)에서 이 리스크가 실제로 발생했을 가능성을 [[2024_ECCV_DQ-DETR|DQ-DETR]] Table 7과 대조해 검증할 필요.

## 방법론적 빈틈 — DQ-DETR이 증명하지 않은 것 (내가 직접 발견한 비판)

[[2024_ECCV_DQ-DETR|DQ-DETR]]의 CGFE 단독 기여(+3.2 AP, Table 5)는 "density map을 encoder feature에 곱해 강조한다"는 아이디어 자체가 유효하다는 근거로 자주 인용되지만, **다시 뜯어보면 이 논문은 두 가지를 증명하지 않았다**:

1. **Density map의 공간적 정확성 자체를 검증하는 실험이 없다.** Table 7의 "CCM 분류 정확도(94.6%)"는 density map을 average pooling으로 요약한 뒤 "이미지 전체에 객체가 몇 개 있는지"를 4단계로 분류한 정확도일 뿐, **"어디에" 객체가 있는지(density map의 공간적 모양이 실제 GT 객체 위치와 얼마나 겹치는지)를 직접 검증하는 정량 지표(IoU, correlation 등)는 노트에 반영된 범위에서 없다.**
2. **"CCM이 예측한 진짜 density map"과 "아무 신호나 넣은 경우(예: 전부 1인 uniform map, random map)"를 비교하는 대조 실험이 없다.** Table 5의 ablation은 CC/DQS/FE 모듈을 통째로 켜고 끄는 것만 비교하지, **"FE(CGFE)의 +3.2 AP가 density map의 정확성 덕분인지, 아니면 attention 연산 자체(어떤 신호를 곱하든 생기는 정규화·비선형성 효과)가 주는 이득인지"를 분리하지 않는다.**

→ **즉 "density map이 잘 나온다"는 것과 "density map이 CGFE의 성능 향상에 실제로 기여한다"는 것 둘 다, 이 논문만으로는 엄밀히 증명되지 않았다.** 내 연구에서 C3 강화를 설계한다면, ablation에 **uniform/random 활성화 맵 대조군**을 반드시 포함해서 "내 강조 신호가 실제로 유의미한지"를 직접 검증해야 한다 — DQ-DETR이 건너뛴 지점을 메우는 것 자체가 기여점이 될 수 있음. **[나중에 내 연구에 쓸 것 — 직접 발견한 비판 포인트]**

## 창의적 변형 아이디어 (메모)
- 강조 대신, offset 예측(`linear_offset`)의 입력에 "밀집 영역 힌트"를 concat해서 attention의 자유도는 유지하면서 힌트만 제공
- 이진/이산 강조가 아니라 [[Gaussian_Box_Uncertainty_Modeling]] 계열처럼 연속적인 확률 분포로 강조
- 레벨별로 강조 강도를 다르게(C3는 세게, C6는 약하게)
- 강조 모듈을 학습 시에만 두고 추론 시 제거(ORFENet의 ORB, FFSSTDNet의 FSR과 같은 "학습시에만 존재하는 auxiliary branch" 계보)
